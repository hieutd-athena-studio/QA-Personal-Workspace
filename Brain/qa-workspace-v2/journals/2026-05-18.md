## Traps

- `pnpm` 11 broken with corepack v1 on Node 20 — use `npm i -g pnpm@9` instead, disable corepack pnpm shim first (`corepack disable pnpm`)
- PowerShell exec policy blocks `.ps1` shims by default — invoke via `cmd /c "pnpm ..."` from PS
- `pnpm create electron-vite` dlx has ENOENT extraction bug on this box — use `npm create @quick-start/electron@latest <name> -- --template react-ts` instead
- `build/` dir was in original `.gitignore` template — un-ignore it; electron-builder uses it for icons + entitlements
- Vitest 4 errors on no-test-files runs — use `--passWithNoTests` until first test lands
- Husky v9 `pnpm prepare` sets `core.hooksPath = .husky/_` (shim dir, gitignored); hook files in `.husky/<name>` are sourced by shims
